# sane_cups_bash_editor
Bash tool to configure SANE and CUPS via CLI.

## Quick install:
```bash
sudo bash -c "$(curl -fsSL https://raw.githubusercontent.com/DemonDED/sane_cups_bash_editor/refs/heads/master/installer.sh)"
```

## Manual install:

### LTS Version:

```bash 
cd /tmp
wget https://github.com/DemonDED/sane_cups_bash_editor/archive/refs/heads/master.zip
unzip master.zip
cd sane_cups_bash_editor-master
sudo ./local_installer.sh
```

### DEV Version:

```bash 
cd /tmp
wget https://github.com/DemonDED/sane_cups_bash_editor/archive/refs/heads/develope.zip
unzip develope.zip
cd sane_cups_bash_editor-develope
sudo ./local_installer.sh
```
